# :material-heart: Support IntenseRP Next

If IntenseRP Next v2 made your setup easier (or saved you from paying for an API), thank you for using it!

This project is built and maintained by [one person](https://github.com/LyubomirT), so a little help goes a long way. There is absolutely no pressure to donate, though. Stars, bug reports, and thoughtful feedback are already huge.

---

## :material-star: The easiest ways to help

If you are not sure what to do, starring the repo and reporting what you tried (even if it "just didn't work") is genuinely helpful. It makes the project easier to discover, and it gives me real-world signals about what breaks first.

<div class="grid cards" markdown>

-   :material-star: **Star the repository**

    Stars are a simple signal that the project is useful, and they help other people find it.

    [:arrow_right: Star on GitHub](https://github.com/LyubomirT/intense-rp-next/stargazers)

-   :material-bug: **Report bugs**

    If something breaks, please open an issue with your version, OS, and what you did right before it failed. Logs (redacted) are extra helpful.

    [:arrow_right: Open issues](https://github.com/LyubomirT/intense-rp-next/issues)

-   :material-lightbulb: **Suggest features**

    Ideas are welcome - especially if you include your use case and what "done" would look like for you.

    [:arrow_right: New issue](https://github.com/LyubomirT/intense-rp-next/issues/new/choose)

-   :material-code-braces: **Contribute code**

    PRs are welcome, even small ones (docs fixes, cleanups, bugfixes). If you're unsure, start by opening an issue first.

    [:arrow_right: View the repo](https://github.com/LyubomirT/intense-rp-next)

-   :material-message-text: **Give feedback**

    If you have thoughts about UX, defaults, docs clarity, or what feels confusing, I'd be glad to hear it. :)

    [:arrow_right: Contact options](contact.md)

-   :material-share-variant: **Share it (optional)**

    If you know someone who would benefit from a "DeepSeek/GLM in SillyTavern" bridge, sharing the docs or the repo is appreciated.

</div>
