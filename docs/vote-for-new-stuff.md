# :material-lightbulb: Vote for New Stuff

There are now regular mini-surveys where you can share how the project is
working for you, what feels rough, and what kinds of new features you'd
actually like to see next.

These are meant to stay lightweight. You don't need to write an essay (unless
you want to, that is!). Just a few questions to get a better sense of what the community wants and needs, and how
the project is doing overall.

If you want to help shape what gets prioritized, this is one of the easiest ways to do it:

[Open the latest mini-survey](https://forms.gle/JCe8FQ27mPgdEGes7){ .md-button .md-button--primary }
